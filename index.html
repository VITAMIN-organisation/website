VITAMIN

Verify Multi-Agent Systems
directly from the browser.

VITAMIN is an online verification framework where models, logics, and algorithms can be combined, extended, and executed through a web Workbench.

Use VITAMIN your way

Choose an entry point that matches your experience with formal verification.

Non-experts

Start with examples and guided visual editing. Explore formal verification without needing to learn the model file format first.

Experts

Use your knowledge of formal models and specification logics. Work directly with model files and inspect detailed verification results.

Developers

Extend the modular core with new model formalisms, logics, parsers, or verification algorithms. Integrate independent components into the framework.

Supported models and logics

VITAMIN separates the main ingredients of the verification process: models, logics, and verification algorithms.
This modular design makes it possible to extend the framework with new formalisms and procedures.

A modular architecture for verification

VITAMIN separates model parsing, formula parsing, and verification algorithms into independent layers.
The engine connects these components and returns a consistent verification result.

Workbench / host app
→
Engine runner
→
Model and formula parsers
→
Explicit-state algorithm
→
Verification result

Parser layer

Model parsers read .txt model files and build in-memory game structures. Formula parsers translate logical specifications into trees used by the algorithms.

Engine layer

For most logics, the shared runner validates inputs, selects the model parser, loads the model, invokes the checker, and normalises errors. Other checkers load models directly.

Algorithm layer

Each logic is implemented through an explicit-state model-checking algorithm that evaluates the parsed formula over the parsed model and returns a standard result.

Implementation note: Current algorithms are explicit-state, making them readable and trace-friendly, although large models can be memory-heavy.
